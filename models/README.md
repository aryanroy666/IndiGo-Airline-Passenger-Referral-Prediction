# models/

Trained model files (`.pkl`, `.jlib`) are generated by running the notebook end-to-end
(see the "Future Work" section) and are intentionally **not committed** to this repo,
in line with standard practice for keeping ML repos lightweight.

Run the notebook locally to regenerate:
- `svm_model.pkl` — final tuned SVM classifier, saved with `pickle`
- `svm_jlib` — the same model, saved with `joblib`
